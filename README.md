# 📋 Formulário de Cadastro

Este repositório contém um projeto simples de **formulário de cadastro responsivo**, desenvolvido em **HTML** e **CSS**, com foco em layout, responsividade e boas práticas de estilização.

## ✅ Funcionalidades

- Campos para nome, sobrenome, e-mail, celular e senha
- Validação básica de preenchimento (`required`)
- Seleção de gênero por radio buttons
- Design responsivo para diferentes tamanhos de tela
- Separação de layout com imagem ilustrativa

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Google Fonts (Inter)
- Layout responsivo com media queries
